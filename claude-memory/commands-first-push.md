For any feature request: (1) check first whether event commands can do it; (2) PUSH FOR COMMANDS FIRST and say so;
(3) if it truly needs a little editor modification, do it and combine it with lots and lots of commands; (4) write the
commands up in CommandList.docx WITH A TUTORIAL (how to use them, an example).

**Why:** the user loved that I pushed for commands on the magic-weapons request (b617) and wants to hear that every time.
**How to apply:** before building, say what commands can cover and what (little) editor change is unavoidable and why,
then go without long debate. Related: [[commands-only-from-now]], [[u6-commands-first]], [[commandlist-progress]].
